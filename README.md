# Fake News Detection System

## Objective

The Fake News Detection System is a Machine Learning application that classifies news articles as Real or Fake using Natural Language Processing (NLP) techniques.

## Features

* Fake News Detection
* Real News Detection
* TF-IDF Text Vectorization
* Logistic Regression Model
* Confidence Score
* Interactive Streamlit Web Interface

## Dataset

The project uses the Fake and Real News Dataset containing:

* Fake News Articles
* Real News Articles

Total Records: 44,898

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Streamlit
* Joblib

## Machine Learning Workflow

1. Data Loading
2. Data Preprocessing
3. TF-IDF Vectorization
4. Train-Test Split
5. Logistic Regression Training
6. Model Evaluation
7. Web Application Deployment

## Model Accuracy

Accuracy Achieved: 98.59%

## How to Run

Install dependencies:

pip install -r requirements.txt

Train model:

python train.py

Run application:

python -m streamlit run app.py
